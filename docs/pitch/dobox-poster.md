- 方針: DoboX のデータが「作品のどこで何をしているか」を主役にする。PLATEAU は「建物の高さを与える土台」として脇に置く。
- 紙面配分の目安: DoboX 関連ブロック（B・C・D・F）で紙面の半分以上。
- 数値は data/README.md の実数（避難場所 442、土砂災害警戒区域 843）だけを使う。河川観測所の件数は【要記入】。

## 各ブロックの見出しと本文案

### A. タイトル帯

- 見出し: **広島 3D 多言語避難ナビ**
- サブ: DoboX の防災データ × 3D 都市モデルで、「今いる建物でどう動くか」を 4 言語で
- QR: https://class-now.github.io/hiroshima-evac-nav/

### B. DoboX のデータでできること

- **避難所情報 → 「どこへ逃げるか」**
  広島市中・東・南・西区の避難場所 442 か所を地図に表示。災害の種類（洪水・高潮・津波・土砂）ごとに使える場所だけから、近い順に 3 件を方角と直線距離で示す。
- **土砂災害警戒区域 → 「ここは危ないか」**
  中・東・南・西区の警戒区域 843 区域を地図に重ねる。選んだ地点が区域内なら注意を出す。
- **河川水位 → 「今、川はどうか」**
  観測所一覧と水位日集計を毎日取り込み、観測所ごとに最新の水位を基準水位と比べて地図に表示。観測所数: 【要記入】。

### C. メイン画面

- キャプション: 建物の色は PLATEAU の浸水深。茶色の面は DoboX の土砂災害警戒区域、ピンは DoboX の避難所情報、観測所マーカーは DoboX の河川水位。
- 引き出し線で各要素に「DoboX」「PLATEAU」「国土地理院」のラベルを付ける。

### D. 使い方 3 ステップ

1. 地図の建物をタップ（または「いまの場所」）
2. 浸水の深さと「N 階より上へ」／「避難場所へ」が出る
3. 近い避難場所 3 件と、近くの川の水位を確認

### E. 4 言語

- やさしい日本語・English・简体中文・한국어
- 避難場所の名前は機械翻訳しない。ローマ字＋施設の種類（例: elementary school）で示す
- 着想: 【要記入: 本人の体験・動機（1〜2 文）】

### F. データの流れ

- DoboX のサーバーはブラウザから直接読めない（CORS なし）ため、Python スクリプト（標準ライブラリのみ）で GeoJSON に変換して同梱
- 河川水位は日本国内のマシンで毎日取り込み、コミットすると公開ページに反映（DoboX は国外から接続できないため、GitHub のクラウド実行は使わない。docs/river-data.md）
- 最寄り避難場所・方角はブラウザ内で計算。外部 API に頼らない

### G. 使用データと出典

下の「使用データ一覧」を表で掲載。

### H. 限界・注意

- 浸水深は想定最大規模の予測値。避難の判断は広島市の発表に従う
- 避難場所までの距離は直線距離
- 河川水位は日集計。リアルタイムの警報の代わりにはならない

## 制作メモ

- 文字サイズ: 見出し 18pt 以上、本文 9〜10pt を下限に。
- 色: 浸水深は水害ハザードマップ作成の手引きの凡例色、土砂は茶系（アプリと同じ #D9A35B）。DoboX ブロックは枠色をそろえて「DoboX 由来」と分かるようにする。
- スクリーンショットは撮影日を小さく併記（河川水位は取り込み日も）。
