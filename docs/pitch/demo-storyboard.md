# 3 分デモ動画 絵コンテ

> 自動で作る版: `npm run pitch:video`（`scripts/pitch/video.mjs`）がこの 12 カットを Playwright で録画し、ffmpeg で日本語字幕を画面下の帯に焼き込む（BGM なし）。英語字幕は `out/demo-en.srt`。初版（`out/demo.mp4`）は 3D なしの暫定。詳しくは `out/README.md`。

- 形式: 画面録画＋字幕のみ（ナレーションなし、BGM は任意）。合計 180 秒。
- 字幕: 日本語と英語を上下 2 段で併記（上: 日本語、下: English）。1 字幕は 2 行以内、表示 3 秒以上。
- 用途: PLATEAU AWARD の提出動画を想定。UDC・DoboX でも流用可。
- 画面の数値（浸水深・距離など）は撮影時の実画面に出たものをそのまま使う。字幕に数値を書く場合は撮影後に実画面から転記する。

## 撮影前チェックリスト

- [ ] 最新版が GitHub Pages に反映されている（またはローカル `python3 -m http.server 8000` で撮る。どちらで撮ったか記録）
- [ ] 開始 URL: `https://class-now.github.io/hiroshima-evac-nav/?spot=peace&lang=ja-easy`
  - `?spot=` は `station` / `peace` / `hondori` / `castle`
  - `?lang=` は `ja-easy` / `en` / `zh` / `ko`
- [ ] カット 9 用に言語別 URL を控える（`?spot=peace&lang=en` など）
- [ ] 画面サイズ: PC カットは 1920×1080（またはウィンドウ 1280×720 以上）、スマホカットは開発者ツールのデバイス表示で 375px 幅
- [ ] ブラウザの拡大率 100%
- [ ] ブックマークバー・拡張機能のアイコン・通知を隠す（OS の集中モード／おやすみモードを ON）
- [ ] 他のタブ・個人情報（アカウント名、履歴の候補）が映らない。シークレットウィンドウ推奨
- [ ] 現在地を使うカットは、実際の居場所が映らないよう地図中心からの検索で撮る（または撮影場所が特定されないことを確認）
- [ ] 3D Tiles を一度読み込んでキャッシュさせてから撮る（1 回通しでリハーサル）
- [ ] 初回案内を撮るカット 10 の前に、サイトデータを消すかシークレットウィンドウを開き直す
- [ ] 河川水位のデータが当日分まで取り込まれていることを確認（取り込み日を控える）
- [ ] マウスカーソルが見やすい（必要なら OS の設定で大きくする）

## 撮影手順（OS 標準の画面録画で可）

1. カットごとに分けて録る（後で並べる方が撮り直しが楽）。各カットの前後に 1〜2 秒の余白を入れる。
2. 録画ツール
   - macOS: `Shift + Command + 5` → 「選択部分を収録」でブラウザ領域を選ぶ
   - Windows: `Win + Alt + R`（Xbox Game Bar）、または Snipping Tool の録画
3. 操作はゆっくり。タップ（クリック）の前に 0.5 秒カーソルを止める。カメラ回転は 1 周 5 秒以上かける。
4. 録画後、動画編集ソフト（OS 付属のもので可）で 12 カットを並べ、表の秒数に合わせて切る。
5. 字幕を入れる（日本語上段・英語下段、画面下部の結果シートと重ならない位置）。
6. 書き出し後に通しで見て確認: 合計 180 秒以内／字幕の誤字／個人情報が映っていない／出典カットがある。
7. 書き出し設定: 1080p、MP4（H.264）。提出先の形式・容量の指定は応募要項で本人が確認する。
