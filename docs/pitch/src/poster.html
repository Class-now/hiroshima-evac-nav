暫定画面（3D 建物・背景地図なし）【本人】差し替え 2026-10-22 撮影

  • DoboX避難場所のピン、土砂災害警戒区域（茶色の面）、河川観測所の「水」マーカー
  • PLATEAU3D 建物と、その色（建物ごとの浸水深）、浸水想定区域
  • 国土地理院避難場所の災害種別・備考、背景地図

使い方 3 ステップ

  1. 地図の建物をタップ（または「いまの場所」）
  2. 浸水の深さと「N 階より上へ」／「避難場所へ」が出る
  3. 近い避難場所 3 件と、近くの川の水位を確認

4 言語

避難場所名は機械翻訳せず、ローマ字＋施設の種類（例: Motomachi Elementary School）に日本語名を並べる。着想: 【本人】体験・動機を 1〜2 文で

限界・注意

  • 浸水深は想定最大規模の予測値。避難は広島市の発表に従う
  • 避難場所までの距離は直線距離
  • 河川水位は 1 日 1 回の取り込みで、警報の代わりではない

データの流れ（DoboX → アプリ）

DoboX避難所・警戒区域・河川水位
Python で変換河川水位は国内の PC で毎日
GeoJSON・JSON を同梱442 か所・843 区域・37 か所
ブラウザで表示最寄りも端末内で計算

DoboX はブラウザから直接読めず（CORS なし）国外からも接続できないため事前に変換。PLATEAU の 3D Tiles は直接読む。
